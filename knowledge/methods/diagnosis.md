# Диагностика и решение — версия 1

Область: анализ расходов и воронки, ставки, выбор наблюдения или эксперимента.
Первичный источник: [Яндекс, модели атрибуции](https://yandex.ru/support/metrica/ru/reports/attribution-model), проверен 2026-09-18.
Из источника: модель меняет распределение конверсий по переходам. С 20 мая 2026
часть старых моделей отключена; сохранённый отчёт может получить новую модель.
Применимость: отчёты одного контекста. Исключение: одно название периода не
гарантирует одинаковые цели, фильтры, лаг и часовые пояса.

Собственная методика v2, переработка direct-analytics/direct-bids v1:

1. Разложить задачу: расход → трафик → событие → подтверждённый лид → квалификация
   → продажа. Найти самое раннее звено, для которого отсутствуют надёжные данные.
2. Проверить evidence через CLI, затем сравнить цель/атрибуцию/период/область/НДС.
   Указать свежесть получения отдельно от возможной задержки учёта.
3. Сформулировать минимум две правдоподобные причины: неверный интент, разрыв
   объявления и страницы, техническая цель, задержка CRM, цена аукциона,
   изменение состава трафика. Не объявлять причиной простое совпадение по времени.
4. Выбирать проверку, которая различает причины. При малой выборке — наблюдение
   с конечным сроком и нужными данными. Универсального порога кликов/лидов нет.
5. Ставку менять в предложении лишь после проверки стратегии, экономики,
   альтернатив и предельного риска. Конверсия сама по себе не повод повышать её.
6. Зафиксировать план оценки: исходная версия, интервал до/после, основная метрика,
   защитная метрика, лаг, срок остановки. Достаточность выборки обосновать задачей.

Уроки разработки P02-C01 (локальные тесты, не рекламные результаты): пусто ≠ 0;
CPC из сумм; CRM CPL/CAC неизвестны без связи событий; all-site цели не Direct-лиды.
Границы: без политики нельзя назначить рабочий бюджет. Неподтверждённый бизнес-эффект
обозначается гипотезой. Нельзя наследовать числовые пороги v1 как согласованные v2.

## Обратная воронка и сценарии

При создании, пересборке и расширении кампании иди от нужного бизнес-результата:
оплаты → лиды → клики → рекламные показы → доступный коммерческий спрос.
Если задана только цель по лидам, начинай с неё; неизвестную цель по оплатам
не придумывай. Все объёмы считай за один явно указанный период с учётом лага продаж.

В `projects/<id>/business-rules.md` разделяй фактические коэффициенты, усреднённый
опыт владельца, гипотезы и отдельно согласованные ограничения. Для коэффициента
фиксируй источник, период/контекст, знаменатель и неопределённость. Усреднённые
проценты — отправная точка сценария, не норматив, гарантия или значения
по умолчанию для других проектов. При достаточной сопоставимой выборке предпочитай
фактическую воронку; при малой выборке не выдавай случайный результат за устойчивую
конверсию. Покажи чувствительность к явно обозначенным допущениям, не объявляя
сценарный диапазон статистическим прогнозом.

Считай инструментом, используя доли, а не целые проценты:

- Нужные лиды = целевые оплаты / конверсия лида в оплату.
- Нужные клики = нужные лиды / конверсия клика в лид.
- Нужные показы = нужные клики / CTR.

Клики Директа и визиты Метрики не взаимозаменяемы: если известна только конверсия
визита в лид, отдельно укажи допущение о переходе от кликов к визитам. У всех
коэффициентов должно совпадать определение лида: событие формы, уникальный лид
и квалифицированный лид не одно и то же. Не суммируй промежуточные цели как лиды.
При неизвестном или нулевом коэффициенте деления конечный прогноз не вычисляется;
для сценария требуется отдельное явно указанное допущение.

Проверяй коммерческий спрос по Wordstat с периодом, регионами, устройствами и
операторами. Частотность — не гарантированные показы рекламы и не уникальный
охват. Учитывай пересечения фраз, сезонность и долю получаемых показов; неизвестную
долю не заменяй молча на 100%. Одинаковые кампании не удваивают независимый спрос.
При нехватке данных обозначь разрыв, а не объявляй ядро достаточным по числу ключей.

Целевой CPL × сценарная конверсия клика в соответствующий лид даёт условный
ориентир среднего CPC, а не автоматически применяемый потолок аукционной ставки.
Отклонение от усреднённого опыта само по себе не основание остановить кампанию,
исключить ключ или изменить допуск. Согласованные бюджеты, ставки и защитные
ограничения DirectGrant сохраняют силу; сценарий их не отменяет и не расширяет.
