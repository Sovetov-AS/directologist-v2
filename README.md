# Директолог 4.0

Текущий вариант агентства Яндекс Директа. Директор работает в основном чате, четыре специализированных исполнителя — demand, marketing, creative и direct_operator. Цель: качественные обращения и прибыльные оплаченные проекты.

Этот вариант заменяет прежнее содержимое `directologist-v2`. Репозиторий содержит систему, а не клиентские выгрузки: локальная рабочая память, `work/` и личные настройки подключений не опубликованы. История Git сохранена.

## Состав

- `AGENTS.md`, `.agents/skills/`, `.codex/agents/` — правила, навыки и профили.
- `scripts/` — клиенты Директа, Метрики, Wordstat и Битрикс24 на стандартной библиотеке Python.
- `config/` — каталоги методов и шаблоны подключений.
- `docs/` — инструкции и каталоги API.
- `tests/` — локальные тесты с подставными ответами.
- `knowledge/ОБУЧЕНИЕ.md` — отобранные уроки.
- `ПАМЯТЬ.md`, `РЕШЕНИЯ.md` — начальные публичные версии; дальнейшее состояние ведётся локально.

## Начало работы

Требуется Python 3.11+; существующий способ чтения секретов использует macOS Keychain и `/usr/bin/security`. Новых Python-зависимостей нет.

```sh
cp config/yandex-connection.example.json config/yandex-connection.json
cp config/bitrix24-connection.example.json config/bitrix24-connection.json
python3 -m unittest discover -s tests
```

В локальных конфигурациях укажите свой логин Директа, портал Битрикс24 и ссылки на собственные записи Keychain для каждого API. В примере Яндекса задайте отдельный `service`/`account` для Директа, Метрики и Wordstat. Не помещайте токены и webhook URL в Git. Проверьте правила фиксации оплаты для своего портала.

В профилях, навыках и инструкциях сохранены пути исходного рабочего компьютера. При другой установке замените рабочий корень своим абсолютным путём; ссылки на старый архив служат только историческими указателями. Автоматическая загрузка профилей зависит от клиента Codex и отдельно не подтверждена.

Записи внешних систем по умолчанию выключены. Подключение API не даёт поручения изменять рекламу или CRM. Сырые ответы и журналы клиенты сохраняют в `~/.local/share/1pi-directologist4/`, вне проекта.

Документация сохраняет исторические сведения о проверках исходной установки на 12.11.2026. Упоминаемые `work/` и архивные материалы в публичную поставку не входят; эти сведения не заменяют проверку нового подключения. Текущие тарифы, доступность данных и возможности провайдера нужно проверять перед использованием.
