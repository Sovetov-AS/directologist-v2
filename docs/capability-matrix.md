# Матрица возможностей

| Возможность | Локальная проверка | Живой API |
|---|---|---|
| Профили / context / предложения | LOCAL_TESTED | Не требуется |
| Direct Reports / Метрика / CRM bridge | LOCAL_TESTED на ответах | NOT_VERIFIED для нового пользователя |
| Wordstat queue / callback | LOCAL_TESTED | Платный runner не включён |
| campaign.pause / resume / budget / create_off | LOCAL_TESTED, SimulationAPI | DISABLED |
| Модерация, ключи, ставки, объявления, удаление | Не реализованы исполнителем | DISABLED |

`capabilities` возвращает текущее состояние. Исполнитель не принимает произвольный
URL, метод API, shell или SQL из модели. Принятие плана не даёт права внешней записи.
Класс SimulationAPI моделирует контракты; это не адаптер настоящего Яндекс API.
Публикация продукта не подменяет приёмку реальных операций.

Граница: процесс с правом редактирования кода/SQLite может изменить проверки.
В данной архитектуре shell агента не изолирован от политики; автономная запись
в рекламу поэтому не включена. Это существенное незакрытое ограничение, а не
исправляемая настройкой `confirmed=true` деталь. Для live понадобится отдельно
согласованная, проверенная граница исполнения/прав и real API acceptance.
