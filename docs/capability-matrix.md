# Матрица возможностей — 0.2.0

| Возможность | Реализация | Проверка |
|---|---|---|
| Профили, мастер ключей, context, предложения | Локальные инструменты | Тесты; ОС проверяется у пользователя |
| Direct Reports, Метрика, CRM bridge | Реальное чтение через API | Ответы API в тестах; кабинет пользователя отдельно |
| Поисковые запросы / статистика по условиям показа | `direct queries` / `performance` | Scope, формат, микроединицы, выбранная цель проверены |
| Создание поисковой ЕПК, групп, ключей | `direct build`, типизированные операции | Возобновляемый сценарий с подменой API |
| Адаптивные объявления, модерация, запуск | Реальные Ads/Campaigns API | Отдельные стадии, reread и статусы проверены |
| Ставки, автотаргетинг, минус-фразы, бюджет, pause/resume | `direct prepare` → `apply` | Допуск, before/after, журнал, сбои проверены |
| Цикл ведения | Codex + `direct cycle` + отчёты и решения | Локальные сценарии; расписание настраивается у пользователя |
| Уроки и откат | Проверки по заранее согласованным критериям | Импорт оценок; независимость оценщика не доказана кодом |
| Wordstat | Подключение и очередь | Платный runner отключён |
| AI Studio | Контракт делегируемых задач | Только заглушки |
| РСЯ, автоматические стратегии, удаление | Вне текущего исполнителя | Не реализованы |

Реальные рекламные writes реализованы и доступны с DirectGrant v2.
`capabilities` показывает каталог; `context` — состояние допуска выбранного проекта,
но окончательная проверка подключения, лимитов и живых объектов происходит при операции.
Прежние SimulationAPI и план v1 остаются только для совместимости и offline demo.

Доверенный локальный режим не защищает политику от произвольного shell владельца.
Нет обещания мгновенного hard cap расхода: отчёты и остановка запаздывают. Ограничен
размер базовой ставки, не итоговый CPC с внешними корректировками. Автономный цикл
требует доступного локального Codex, сети и хранилища ключей. Реальная API-приёмка
и рекламный результат на аккаунте пользователя не подтверждены тестами продукта.
