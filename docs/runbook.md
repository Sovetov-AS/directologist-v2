# Установка и работа

Система запускается в локальном Codex из каталога репозитория. Нужны Python 3.12+
и виртуальное окружение; команды установки приведены в README.
Навыки обнаруживаются в `.agents/skills/`. Аккаунты и правила поставляются пустыми.

Создайте проект с собственным ID, именем и часовым поясом:

```sh
.venv/bin/python scripts/directologist.py --project my-project project-create --name 'Мой проект' --timezone Europe/Moscow
.venv/bin/python scripts/directologist.py --project my-project setup
.venv/bin/python scripts/directologist.py --project my-project context
```

На Windows имя интерпретатора окружения — `.venv\Scripts\python.exe`.
`project-create` не перезаписывает существующий профиль. `setup` требует
пользовательского TTY; не передавайте ключи в чат, аргументы, environment или логи.
Права каждой площадки и ресурсы выбираются отдельно. Данные лежат только в
`projects/<id>/`; другой пользователь не получает их из репозитория.

Начните в Codex: «Проверь рекламу проекта my-project и подготовь решение».
Главный directologist выберет методику, вызовет расчёты и сохранит предложение.
Подробности: analysis.md, decision-contract.md, connections.md.
Автономные рекламные writes по умолчанию недоступны; план или урок не являются допуском.

Остановка Codex прекращает будущие локальные действия, но не останавливает
показы в Директе. Платформенная остановка — отдельная операция. Восстановление
базы: backup/restore; ключи и JSON evidence требуют отдельного сохранения.
После восстановления сначала сверить незавершённые операции и состояние аккаунта.
