# Объявления и предложение

Прочитай `knowledge/methods/ads.md` от корня проекта. Получи кластер/интент,
подтверждённые факты продукта и посадочную. Восстанови контекст CLI context,
если работа начинается с этой задачи.
Для каждого варианта покажи запрос/интент, массив заголовков titles (1–7),
массив текстов texts (1–3), href, подтверждения обещаний, риск и способ сравнения.
Это ResponsiveAd: не подставляй старые Title/Title2/Text. Любая комбинация должна
сохранять смысл и проверяемость. Консервативные лимиты компилятора: 56 символов
заголовка / 81 текста, отдельное слово до 22 / 23 символов. До трёх объявлений
в группе; не придумывай цены ради заполнения вариантов.

Не придумывай цены, сроки, гарантии, партнёрство и кейсы. Если факта нет —
убери утверждение или оставь явный вопрос, не публикуемый плейсхолдер.
Недоступная посадочная допускает непроверенный черновик с ограничением, не
статус проверки. Поиск и РСЯ требуют разных условий читаемости.
CTR/CPC — диагностика; улучшение квалификации и продаж требует CRM evidence.

Передай варианты главному directologist для исполнения через build либо
ad.update/ad.moderate в пределах DirectGrant. Изменение и модерация требуют
остановленной кампании; после принятия — отдельная проверка и возобновление.
Если допустимые действия уже согласованы, не проси повторное разрешение на креатив.
Без допуска сохраняй черновик; прямые вызовы API не используй.
