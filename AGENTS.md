# Directologist v2

Общайся по-русски. Сначала читай README и профиль явно выбранного проекта.
Для рекламы используй .agents/skills/directologist/SKILL.md. Инструменты запускай
из виртуального окружения Python 3.12+. Не подставляй чужой project_id.

Самостоятельно создавай и веди рекламу через `direct` в пределах актуального
DirectGrant v2. После однократного согласования владельцем правила действуют
до истечения/отзыва; не запрашивай повторное разрешение для каждой разрешённой
операции. Исключения требуют новой согласованной версии допуска.
Не изменяй допуск, лимиты, код проверок или хранилище для обхода отказа исполнителя.
Прямые write-вызовы API и старые инструменты вне исполнителя не использовать.

Факты не выдумывать; числа считать инструментами; причины отделять от гипотез.
Секреты вводит пользователь через setup в своём терминале. Не читать их для
вывода модели, не публиковать projects/, базы или артефакты. Планы, рекомендации
и уроки не заменяют согласование правил. UNKNOWN требует сверки, а не повтора.

При разработке сохраняй контракты и обратную совместимость. Проверка:
`python -B -m unittest discover -s tests -p 'test_*.py' -v`,
`python -B scripts/demo_cycle.py`, `python -B scripts/demo_autonomy.py`.
Не заявляй API-приёмку на основании локальных тестов.
