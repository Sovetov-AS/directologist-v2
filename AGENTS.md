# Directologist v2

Общайся по-русски. Сначала читай README и профиль явно выбранного проекта.
Для рекламы используй .agents/skills/directologist/SKILL.md; инструменты запускай
из виртуального окружения Python 3.12+. Не подставляй чужой project_id.

Факты не выдумывать; числа считать инструментами; причины отделять от гипотез.
Секреты вводит пользователь только через setup в собственном терминале.
Не читать ключи для вывода модели, не публиковать projects/, базы или артефакты.
Нельзя обходить отключённые live capabilities прямыми вызовами API или старыми скриптами.
Планы, рекомендации и уроки не выдаются за разрешение на расходы.

При разработке изучай существующие контракты, делай минимальные изменения,
сохраняй обратную совместимость. Проверка:
`python -B -m unittest discover -s tests -p 'test_*.py' -v`
и `python -B scripts/demo_cycle.py` из настроенного окружения.
Не заявляй, что реальные интеграции приняты, на основании локальных тестов.
